Política de privacidad

Home Assistant Casita

Home Assistant Casita es una aplicación personal para la automatización del hogar.

Acceso a Google Calendar

La aplicación solicita autorización para acceder a los calendarios de Google del usuario, con el fin de mostrar sus eventos en un panel doméstico de Home Assistant.

Uso y almacenamiento de datos

Los datos del calendario se utilizan para proporcionar la funcionalidad solicitada. Home Assistant puede almacenar información localmente para mantener la integración.

Compartición de datos

El propietario no comercializa los datos obtenidos mediante Google Calendar ni los utiliza para publicidad.

Control del acceso

El usuario puede revocar los permisos concedidos desde la configuración de seguridad de su cuenta de Google.

Contacto

Para consultas sobre privacidad, utiliza el correo de asistencia indicado en la pantalla de autorización de Google.
